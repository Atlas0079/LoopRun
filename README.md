# 圈界 LoopRun

圈界是一款把真实跑步与领地争夺结合的 Android 应用。跑出一个闭环，圈内的街区就会参与领地结算：占领空地、加固自己的区域，或削弱同池跑友的领地。

**Android 内测版 0.5.2** · [产品文档与完整演示](docs/产品文档.md) · [玩法规则](docs/规则.md) · [接入与部署](docs/接入与部署.md)

## 怎样玩

1. **选一片熟悉的区域，开始跑步。** App 记录真实 GPS 轨迹，跑步中可以查看距离、时间和距起点的距离。
2. **跑出闭环，结束并结算。** 至少跑满 600 米、3 分钟，回到起点 80 米范围内，并围住足够的区域。
3. **回到地图，看看发生了什么。** 空地变成你的领地，自己的格子得到加固，对手的格子受到削弱。再用下一次跑步继续扩展或防守。

争夺发生在最多 6 人的匹配池内。系统根据实际跑步区域的部分重叠匹配跑友；没有合适的对手时，可以先独立成池，等待后续跑者加入。

## 在地图上看到每次跑步的变化

- **查看自己的领地与同池争夺。** 六边形格子的颜色对应归属，深浅体现加固程度；中立区域保留清晰底图。
- **把空间留给地图。** 上下抽屉收起统计与选项，地图支持拖动、缩放；跑步时依然保留距离、时间和结束按钮。
- **发现附近的跑者。** 主动分享位置后，附近用户可以看到大致位置。人物默认只显示图标，点击显示名字，再点进入公开详情。
- **回看自己的运动。** 记录页展示距离、有效闭环与领地变化，支持回看本人轨迹。途中断网时先在本机保存，联网后补传。

## 玩法速览

| 规则 | 效果 |
| --- | --- |
| 地图格子 | 六边形对边目标 50 米 |
| 圈住中立格 | 占领，加固值为 1 |
| 圈住自己的格子 | 加固加 1，最高 3 |
| 圈住对手的格子 | 扣除伤害，降至 0 后先变为中立 |
| 当天重复跑同一区域 | 同一用户对同一格，在北京时间同一天最多生效一次 |
| 同池竞争 | 每池最多 6 人，按领地面积查看跑友排名 |

把对手领地打成中立后，还需要另一场符合每日额度的有效跑步才能占领。完整闭环条件、回归伤害和离池规则见[玩法规则](docs/规则.md)。

## 位置与隐私

“公开本次大致位置”默认关闭，由用户在开始前选择。共享图层展示附近 3 km 内仍在分享的跑者，位置约模糊至 80 米；同池显示名字，非同池显示为“附近跑者”。

原始轨迹仅本人可见。真实跑步开始后通过持续通知提示定位记录，停止记录后停止采集。地图使用高德地图，首次使用说明和设置页提供地图服务与隐私政策入口。

## 如何体验

当前通过自行构建 APK 参与内测，支持 Android 7.0 及以上的 ARM64 真机。

1. 按[接入与部署](docs/接入与部署.md)准备跑步服务、地图 Key 并构建安装包。
2. 安装 App，连接服务地址，使用内测邀请口令创建账户。
3. 阅读地图与位置说明，从首页开始真实跑步。

两台手机进行争夺测试时，需要使用不同账户、连接同一环境，并进入同一个有空位的匹配池。路线应部分重叠；户外实时使用需要两台手机都能持续访问服务。[双手机测试条件与步骤](docs/产品文档.md#当前完整性与双手机测试)已整理在产品文档中。

目前已验证主要界面、地图交互、规则与接口流程，以及机器人通过普通 GPS 接口完成真实时长的采样和结算。双手机户外真实 GPS 争夺、锁屏、耗电和弱网体验待专项实测。

## 开发模式

从首页上方抽屉或设置页开启开发者模式，即可进入独立测试环境：

- **虚拟跑步**：选择预设道路闭环，约 14 秒播放后上传并结算，记录标记为开发模拟。
- **机器人用户**：选择路线和起跑位置，启动单个或 5 位预设跑者，在地图上观察多人运动。

机器人按真实时间运行，通过普通用户的登录、跑步、采样、位置分享和结算流程参与，遵守相同的匹配、争夺与每日额度规则。普通与开发环境分别保存账户、领地和记录。

## 开发与文档

客户端使用 React Native、TypeScript、Expo 和高德 Android 原生地图；服务端使用 Fastify、PostgreSQL 与 PostGIS。开始本地开发前需准备 Node.js 24+、Android SDK 和 JDK，具体配置及启动命令见部署文档。
