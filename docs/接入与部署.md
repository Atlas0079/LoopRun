# 接入与部署

## 当前架构

当前交付为 Android 内测 App 与独立 GPS 服务端。客户端使用 React Native、TypeScript、Expo 原生构建，MapLibre / OpenStreetMap 原生地图展示道路与格子，Android 原生前台定位服务持续采样，SQLite 先保存 WGS84 轨迹再分批上传。

GPS 服务端使用 Fastify / TypeScript、PostgreSQL / PostGIS。复用 server/game.mjs 和 shared/geo.mjs，存储拆分玩家、池、领地、活动、采样、会话、邀请和事件，以事务保证结算幂等与写入一致。首轮并发容量待实测。

浏览器道路回放保留 server/index.mjs、独立 SQLite 和 React / Leaflet。它不创建真实 GPS 活动，不接入内测库。规则以[首版规则](规则.md)为准。

## Android 客户端

入口为 apps/mobile/。MapLibre 通过其原生组件绘图；前台定位服务、本机存储与上传在本地 Expo 模块 modules/looprun-native 中，使用可安装的原生构建验证。

首轮使用 MapLibre 与 OpenStreetMap 在线底图，无需地图 Key。保留版权链接，设置应用 User-Agent 并遵守缓存头；只请求正在查看的视口，不提供离线底图下载。正式扩大使用前选择具备用量承诺的底图服务。真机和户外锁屏测试待验证。

定位权限在用户操作时请求。用户从前台开始 location 前台服务，持续通知表明正在记录；首轮不要求全天候定位。服务终止或采样中断时明确显示，不伪造路径。Android Keystore 保护本机身份与会话凭据。

## GPS 服务端

沿用配置、状态、活动开始、结束、取消和详情接口，新增邀请口令登录与递增序号采样上传。批次和结算均可安全重试。未配置内测口令时拒绝创建身份，不内置通用口令。

使用独立 PostgreSQL / PostGIS 空库，既有道路回放数据不迁入，不增加旧版数据兼容分支。本机手机联调可使用 USB adb reverse；远程内测需手机可达的 HTTPS API，域名、服务器与证书待配置。

## 地图与坐标

记录、MapLibre 展示和结算统一使用 WGS84。六边形对边目标 50 米，参考纬度 31.2353 度；扩展地区前检查尺度差异。公开动态位置独立模糊至约 80 米范围。

地图按视口查询和绘制。“我的领地”只显示本人，“同池争夺”显示当前池。跨池公开规则待确认，不将不同池的冲突归属混画成一个世界。

浏览器回放保留 OpenStreetMap 版权标识，正常请求当前视口，不批量预取公共地图。Valhalla 步行折线、道路名和来源在 server/road-routes.json；真实 GPS 不依赖规划折线生成记录。

## 验证状态

既有 19 项规则与接口检查、占领至重新匹配的浏览器结果仍为道路回放验证事实。50 米调整按原道路轨迹与时间重算，不代表真实户外结果。

Android 工程编译、服务端接口、地图鉴权、真机锁屏和耗电分别记录。未执行的项目保持待验证；辅助测试、截图与记录保留在本地 .local-tests/、.local-reports/。

## 本机运行与打包

需要 Node.js 24+。根目录 npm install；在 apps/mobile 执行 npm install。

1. PostgreSQL 18 与 PostGIS：本机已配置独立开发库，执行 npm run gps:db 启动或检查；其他机器可安装 PostgreSQL/PostGIS 并配置 .env.gps.local，示例见 .env.gps.example。
2. 执行 npm run gps:dev，GPS API 默认仅监听 http://127.0.0.1:4180 。内测邀请口令在本机 .env.gps.local 中，不写入客户端或共享文档。
3. 执行 npm run android:build，本机构建签名 release APK，输出 artifacts/LoopRun-0.3.0-android-arm64.apk。首次会下载原生依赖。构建要求 Android SDK 与支持 Gradle 的 JDK；当前机器复用 Android Studio 的 JBR。
4. 内测签名由脚本首次生成并保存在 .local-credentials，后续使用同一签名更新安装包。必须保留该目录，不上传或提交。App 图标由矢量代码生成。

安装包支持 arm64-v8a、Android 7.0/API 24 及以上，包名 com.looprun.android，版本 0.3.0。JS 与原生库已打入 APK，不依赖 Expo Go、Metro 或 Expo 云账号。

手机后续可开启 USB 调试并连接 Mac，然后执行 Android SDK platform-tools/adb reverse tcp:4180 tcp:4180；App 内服务器填写 http://127.0.0.1:4180，再填写本机邀请口令。未连接 USB 时，此回环地址指向手机自身，不能访问 Mac。局域网或公网接入需另行配置地址与监听；当前不默认开放外网。

本轮按用户选择只交付本机版本，不部署公网服务。手机未连接，地图实际加载、真实 GPS、锁屏 30 分钟连续性、耗电、弱网和厂家省电行为均待真机验证。

Android release APK 构建、独立签名验证、16 KB ZIP 对齐、客户端类型与 lint、服务端类型检查、24 项规则/API 检查均已通过。新增 GPS API 检查使用隔离测试库和合成采样，不代表真实手机记录。当前未连接真机或启动模拟器，App 实际启动、底图加载、真实 GPS、锁屏连续性、耗电与厂家后台行为保持待验。

首轮 PostgreSQL 适配器已拆分实体与领地存储，并提供空间索引查询；规则执行仍读实体快照、串行提交事务，后续容量和按池并发优化待验证。
