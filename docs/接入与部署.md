# 接入与部署

## 当前架构

Android App 是唯一客户端交付与验收入口。客户端采用 React Native、TypeScript、Expo Router，高德 Android SDK 绘制原生地图。普通跑步由 Android 前台定位服务采样，本机 SQLite 保存 WGS84 轨迹，断网保留，恢复后分批上传。

普通 GPS 与开发服务均运行 server/gps.ts，使用独立 PostgreSQL / PostGIS 数据库，复用 server/game.mjs、shared/geo.mjs 及原有登录、状态、活动开始、采样、结束、取消和详情接口。GPS 存储包含玩家、匹配池、领地、活动、采样、会话、邀请和事件，以事务保证上传重试与结算幂等。

浏览器源码保留，但不作为当前产品入口或测试验收工具。其 SQLite 回放数据不迁入 Android 的普通库或开发库。

## 普通用户与开发者开关

新安装默认关闭开发者模式。普通模式展示真实跑步、领地、同池跑友、排名与私有历史；只在开始跑步时请求精确定位和所需通知权限，不显示模拟路线、机器人按钮或测试标记。

设置中开启开发者模式，切换到独立开发环境，页面明确标注测试数据。完整用户流程始终保留：主按钮为真实 GPS「开始跑步」，位置分享、地图、领地、同池排名和私有记录照常使用。仅额外增加「开发工具」入口，模拟跑步不替换主按钮。开发工具支持：

- 选择并在原生地图预览道路规划路线。
- 模拟本人跑步，约 14 秒播放完成，再上传采样并结算；不启动真实定位服务。
- 查看机器人正在跑的路线、进度和结果，并在地图预览。
- 暂停所有机器人后，指定其中一位按选中路线跑一圈。
- 启动 5 位自动用户，每人按部分交叠路线跑 4 圈后停止。

两套服务地址、会话及安装身份分别存入 Keystore 保护的本机配置。关闭后恢复普通账户，清空测试地图和记录视图。任何模式切换前，都必须结束或放弃服务器活动，并处理本机待上传轨迹。进行中活动、上传失败或无法确认服务器状态时，不允许静默切换环境。

开发模拟活动保存在服务端。App 中断或重启后，通过自己的状态接口恢复完整模拟路线，可继续上传结算或放弃；重复上传相同序号必须内容一致，重复结算不重复计数。两种环境的真实 GPS 均复用本机 SQLite、前台定位服务、后台采样与上传流程；普通与开发环境分别使用本机数据库，记录与结算结果互不混用。GPS 与模拟活动互斥，停止、上传和取消按当前活动来源处理，不能仅根据开发者开关分流。

## 服务端隔离与权限

普通服务配置 GPS_DEVELOPER_MODE=false，默认 4180；开发服务配置 GPS_DEVELOPER_MODE=true，默认 4182。开发数据库名必须以 _development 结尾，普通服务拒绝该类数据库名。每个库保存固定环境标记，环境不匹配时拒绝启动。

health/config 声明服务环境，Android 连接时与开关状态严格核对。普通服务仅接受真实 GPS，不提供测试路线，拒绝模拟跑步参数与机器人控制；开发服务支持同样的真实 GPS 流程，并额外接受模拟请求；开发控制接口需要正常用户鉴权，不能用界面开关替代服务端隔离。

开发模拟只在创建活动时生成规划轨迹与对应采样时间。其后仍使用正常 points/finish 接口，执行相同的序号、精度、连续性、速度、闭环、匹配、加固、削弱、每日同格额度和淘汰规则。活动来源明确为 simulation，不能作为真实 GPS 记录。

机器人使用同样的 android-beta 用户类型，通过普通邀请码登录并取得会话，开始活动、分批上传采样、结束结算或取消。驱动器不访问存储、不直接修改领地，没有强制同池或绕过每日额度的权限。单独路线控制与自动运行互斥；暂停等待在途请求并取消未完成活动，失败时保留活动以便重试。

开发环境同样使用实际服务端日期，不自动推进日期或重置额度。当天反复跑相同格子不会重复生效。普通与开发邀请码独立保存，不内置通用口令。首轮并发容量待专门实测。

## 地图与位置

原始 GPS、服务器记录、50 米网格和结算使用 WGS84；高德地图显示使用 GCJ-02。轨迹、预览路线、当前位置及领地顶点在本机通过高德官方转换器转换。视口边界通过同一正向转换器迭代求回 WGS84，仅用于查询，不改写记录和网格。六边形对边目标 50 米，参考纬度 31.2353 度；扩展地区前检查尺度差异。公开动态位置独立模糊至约 80 米范围。原始轨迹仅本人可读。

地图回定位按钮位于左上角，高德原生缩放按钮位于右下角，互不覆盖；高德标识和审图信息保持可见。地图按视口展示“我的领地 / 同池争夺”，同池跑友页的颜色与地图领地对应。跨池公开规则待确认，不把不同池的冲突归属混画成一个世界。

底图使用官方高德 Android 3D SDK（11.3.100，固定 Maven 版本），保留 SDK 自带标识与审图信息。Android Key 绑定包名 com.looprun.android 和当前发布/调试签名 SHA-1；通过本地 .local-credentials/amap.json 的 androidKey 或 LOOPRUN_AMAP_KEY 环境变量提供，不提交 Key 或生成的 Manifest。Key 变更后构建自动重新生成原生工程。授权、配额和使用范围按高德控制台核实。SDK 在用户确认高德地图用途后初始化，升级后的用户需重新确认；设置提供 SDK 提供方、信息用途与官方隐私政策链接。开发路线来源、道路名和 Valhalla / OpenStreetMap 规划折线位于 server/road-routes.json，规划结果不保证道路实时可通行，真实 GPS 不依赖规划路线生成采样。

定位权限由用户操作触发，普通跑步从前台启动 location 前台服务，以持续通知提示记录；首轮不要求全天候定位。服务终止或采样中断必须明确显示，不补造缺失轨迹。

## 本机环境

需要 Node.js 24+。根目录与 apps/mobile/ 分别执行 npm ci。

1. 安装 PostgreSQL 18 与匹配的 PostGIS，或将官方二进制解压至 .local-tools/pgsql 并安装同主版本 PostGIS；也可通过 PG_BIN 指定 bin 目录。
2. npm run gps:db 首次生成 .env.gps.local，初始化本机实例和普通库，验证 PostGIS。默认实例只监听 127.0.0.1:55432，已有本机配置按 DATABASE_URL 的用户名、端口及库名运行；远程数据库独立管理。普通配置示例见 .env.gps.example。
3. npm run developer:db 复用本机实例凭据，创建独立 looprun_development 库与 .env.development.local，并生成不同的开发邀请码。
4. 分别执行 npm run gps:dev 与 npm run developer:dev，启动 4180 普通服务和 4182 开发服务。普通环境配置不得指向开发库。
5. npm run android:build 构建本机签名 release 包，默认输出 artifacts/LoopRun-0.4.2-android-arm64.apk；仅支持 ARM64 真机。构建前配置本地高德 Android SDK Key。

Android 构建使用 Android SDK 与支持 Gradle 的 JDK。优先读取 JAVA_HOME、ANDROID_HOME 或 ANDROID_SDK_ROOT。Windows 默认查找 Program Files 下 Android Studio JBR 和 LocalAppData/Android/Sdk；macOS 默认查找 Android Studio JBR 和 ~/Library/Android/sdk；Linux 可显式配置。

脚本按平台选择 Java、路径分隔符与 Gradle 启动方式。Windows 深层目录需使用支持长路径的 Ninja。本机 SDK CMake 3.22.1 的 Ninja 已更新为官方 1.13.2，旧工具保留在 .local-tools/ninja/ninja-sdk-1.10.2.exe。其他机器检查 SDK cmake/3.22.1/bin/ninja.exe，使用[官方 Ninja 1.13.2 或更新版本](https://github.com/ninja-build/ninja/releases)。

签名由脚本首次生成并保存在 .local-credentials，之后复用同一签名更新安装包。必须保留，不上传或提交。包名 com.looprun.android，版本 0.4.2，versionCode 4；Android 7.0/API 24 及以上。JS 与原生库打入 APK，不依赖 Expo Go、Metro 或云构建账号。原生 Android 工程通过 Expo 配置生成，不直接手改生成目录。

## 手机连接

手机开启 USB 调试连接电脑后，用 SDK platform-tools/adb（Windows 为 adb.exe）执行：

```
adb reverse tcp:4180 tcp:4180
adb reverse tcp:4182 tcp:4182
```

App 默认普通模式，设置填写 http://127.0.0.1:4180 和普通邀请码；开启开发模式后填写 http://127.0.0.1:4182 和开发邀请码。关闭时恢复普通连接。未连接 USB 时，回环地址指向手机自身；局域网与公网需另行配置监听、可达地址和 HTTPS。当前只配置本机，不部署公网。

此前 19 项规则与接口检查、占领至重新匹配的浏览器结果，是既有道路回放测量事实；50 米调整按原道路与时间重算，不代表户外结果。此前 Android 0.3.0 release 构建、签名、16 KB ZIP 对齐、类型/lint 及 24 项规则/API 检查曾通过，新增 GPS 检查使用隔离库与合成采样。这些既有结果不能代替本轮开发者模式的验证。

本轮客户端类型、lint、原生构建、服务端隔离、模拟上传、机器人路线与实际设备结果分别记录在本地验证资料中。未执行项目保持待验证。地图切换后的真机底图与坐标叠加、真实 GPS、锁屏 30 分钟连续性、耗电、弱网及厂家省电行为均需真机验证，不能用编译或模拟路线结果替代。

测试用例、辅助脚本、截图与验证记录保留在本地 .local-tests/、.local-reports/，默认不提交。存储当前仍读取实体快照、串行提交事务；按池并发与容量优化需另行测量和确认。
